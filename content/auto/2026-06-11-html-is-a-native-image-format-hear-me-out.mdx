## 1. 可组合性，而非像素

模型接下来生成的将不再是图像，而是一份文档。图像将所有内容扁平化为一个冻结的栅格（raster）。HMML则保留各个组成部分——矢量（vector）、文本（text）、栅格（raster）、3D、动态（motion）——使其保持可组合（composable）和可编辑（editable），以节点（node）为粒度创建，而非基于1024网格的猜测。

## 2. 四大核心特性

01 可组合，而非扁平化：一张照片、一个图标、一张图表、一个3D场景——图像将它们压缩成一个栅格。HMML则保持每个元素独立：可分层（layered）、可寻址（addressable）、可重组（recomposable）。
02 细粒度原语（Fine-grained primitives）：以元素、变换（transform）、关键帧（keyframe）为粒度进行创建和编辑——修改一个节点，而非整个渲染结果。可进行差异比较（diff）、版本控制（version）、混搭（remix）。
03 可编辑，而非冻结：事后可重新设置样式、本地化、添加动画。生成的输出保持为源文件——而非只能重新生成的截图。
04 模型原生（Native to models）：模型已经能编写HTML、CSS和SVG。HMML只是将这种输出，连同原始媒体（raw media），封装成一个可移植的契约（portable contract）——一个约2KB的读取器可在任何地方打开它。模型是否会进化到直接输出这种格式？也许，也许不会。但“图像”这个词已经承载过多含义——照片、图标、图表、场景、动画，全部被压缩成一个冻结的栅格。HMML解除了这种混淆，无论哪种情况都能发挥其用途。或者，也许像素一直就够用了。让我们拭目以待。

## 3. 过去与现在：从手动组装到挂载场景

你不再构建场景，而是挂载（mount）它。
过去：你手动连接布局、样式、状态以及一个包含若干扁平AI图像的资源文件夹。
现在：模型将整个场景作为一个文件输出——你的应用只需获取（fetch）、解码（decode）并将其挂载到一个div中。所有复杂性都下载到.hmml文件内部。

过去——你手动组装每个部分：
div class="product"
  img src="ai/hero-1.png"
  img src="ai/hero-2.png" // AI的全部工作
  div class="copy"
    h2 你手写这个 /h2
    p ...还有这个。以及alt文本。 /p
    button onclick="addToCart()" 购买 /button
  /div
/div
style
  .product&#123; display:grid; gap:24px &#125; /* +40行 */
/style
script src="layout.js" /script
script hydrate(); wireCarousel(); track() /script
!-- + /assets: 14个文件, + 状态, + 构建步骤 --

未来——获取-解码-挂载 场景 = 100% AI：
div id="scene" /div // 挂载div
script type="module"
  import &#123; unpack &#125; from "@eddocu/hmml"
  const bytes = await fetch("scene.hmml").then(r =&gt; r.arrayBuffer())
  const doc = await unpack(new Uint8Array(bytes)) // 解码
  scene.innerHTML = doc.toHTML() // 挂载
/script
// 一个文件 = 布局 + 媒体 + 动态 + 逻辑

## 5. 契约：比特与字节

一个契约。类似PNG的签名，然后是自描述的数据块（chunks）。标记（Markup）保持为文本；图像保持为原始格式。未知数据块被跳过——它可以在不破坏兼容性的情况下扩展。完整规范→

89 'H' 'M' 'M' 'L' 0D 0A 1A 0A · major · minor · codec
MARK 标记 - HTML / CSS / SVG / JS，可gzip压缩的文本
RSRC 资源 - id + mime + 原始字节（无base64）
META JSON元数据
ENDF 结束标记
· 标记通过 hmml:id 引用资源

## 6. 两个调用：编码与解码

// 编码 — pack(html) → 一个.hmml文件（一个Uint8Array，可存储或发送）
// · 将HTML中的所有data:图像提升为原始字节（无base64）
// · 对HTML/CSS/JS进行gzip压缩，并将所有内容封装为一个二进制blob
const bytes = await pack(html)

// 解码 — unpack(bytes) → 返回文档，可在任何浏览器中运行
// · 从blob中读取标记和原始图像
// · toHTML() 将它们重新拼接成可渲染的HTML，供你挂载
const doc = await unpack(bytes)
el.innerHTML = doc.toHTML()
// （或使用doc.createObjectUrls()获取blob: URL）

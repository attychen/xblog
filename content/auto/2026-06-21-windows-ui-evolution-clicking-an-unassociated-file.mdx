## 1. 引言：一个有趣的小实验

（我不打算写更多关于Windows UI的博客文章了。只是偶然发现这个，觉得挺有意思。再说，我住的地方现在超级热，什么有意义的事都做不了，所以就来写写吧。）让我们打开文件管理器，点击一个既不是.EXE也不是系统已知类型（如.TXT）的文件。会发生什么？我无法接触到所有版本的Windows，只有少数几个。让我们看看这些版本的情况。我还把一些德语标签翻译成了英语，但很可能这些按钮在原始英语版本中叫法略有不同。

## 2. 早期版本：Windows 386/2.11 (1989) 和 Windows 3.1 (1992)

在Windows 386/2.11 (1989)中，你只会得到一个“不行”（图片翻译：“ABC.OMG不可执行”）：这个版本的Windows已经有了“用程序$bar打开文件类型$foo”的概念，但显然没有配置这个的UI。或者我没找到。你可以在WIN.INI中设置关联：Windows 3.1 (1992)稍微改进了情况：它仍然只是告诉你“不行”，但现在也告诉你存在文件类型关联的概念以及在哪里配置。这会带你到一个基本但功能性的对话框：顶部的文本框让你输入文件扩展名，底部的列表框允许你选择已安装的程序之一。如果它不在列表中，你可以点击“Durchsuchen...”（“搜索...”）按钮来选择任意程序。

## 3. Windows NT 3.1 (1993) 和 Windows 95 (1995)：逐步改进

Windows NT 3.1 (1993)基本上是一样的（顺便说一句，Windows for Workgroups 3.11也是如此）：Windows 95 (1995)是一个巨大的进步，因为你现在会看到一个对话框，可以直接在那里选择所需的程序——不再需要导航到其他地方：如果程序没有列出，你可以点击“Andere...”（“其他...”）按钮直接选择一个程序。这种行为在Windows 98、Windows ME和Windows 2000中保持不变——以下是后者的截图：

## 4. Windows XP (2001)：引入网络服务尝试

然后Windows XP (2001)出现了，它现在试图推动你使用某种网络服务，因为互联网“终于”无处不在™：遗憾的是，我不再知道那是什么网络服务了。如果你知道，请告诉我。它很可能是由微软运营的，但它的数据库是什么？它列出了哪些程序？它如何查询这个数据库——是上传整个文件还是部分文件，还是仅仅上传文件扩展名？它是否提供在你的PC上安装程序？（我依稀记得这个服务曾被用作某种攻击向量，杂志上写着“不要使用这个！！1！”，但我不确定了。）——编辑：好吧，正如一位读者告诉我的，这只是在Internet Explorer中打开一个网站，将文件扩展名作为查询字符串发送。他们说该服务自2006年以来已关闭。而且显然它非常没用。读者推测只有微软认证的合作伙伴可能最终出现在这里，并指出即使是像.3GP这样的流行文件类型也无法识别。你可以自己尝试一下，通过询问互联网档案馆：https://web.archive.org/web/20130530100029/http://shell.windows.com:80/fileassoc/0404/xml/redir.asp?EXT=3gp 来自Protoweb存档的截图本地副本（尺寸缩小）：如果你不想使用那个服务，你可以选择第二个单选按钮来进入旧对话框：

## 5. 跨越到Windows 10 (2015)：扁平化时代的到来

现在有一个很大的空白。我无法接触到Windows XP和Windows 10之间的任何版本。所以，接下来是Windows 10 (2015)：哎呀，我们显然已经进入了“一切扁平化”的时代，你很难再分辨屏幕上的哪些项目是可交互的。甚至连窗口装饰都消失了。顶部的文字（“Im Store nach einer App suchen”——“在商店中搜索应用”）实际上是一个可以点击的按钮（图标可能意在表明这一点？）。“Weitere Apps”（“其他应用”）也是可以点击的（通过颜色指示，像网页链接一样），它会打开一个列表：再次，这显示了已安装的程序。抱歉，它们现在被称为“应用”了。你可能无法立即看出的是，你可以滚动这个窗口来显示第三个选项：如果列表中没有你想要的程序，你可以点击按钮/文字/任何东西“Andere App auf diesem PC suchen”（“在此PC上查找其他应用”）。就是这样。

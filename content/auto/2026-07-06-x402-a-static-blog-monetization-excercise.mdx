## 1. 引言：Cloudflare 变现网关的革新意义

x402，一个静态博客变现实验，发布于2026年7月5日。几天前，Cloudflare 发布了一则关于变现网关（Monetization Gateway）上线的公告。这之所以具有革命性，原因有很多。它移除了变现的高门槛，让你能够非常精确地控制收费内容以及最低支付金额。这实际上可以改变我们使用互联网的方式，使互联网赖以生存的广告经济模式变得过时。例如，它听起来像是变现博客或 API 的理想工具。尽管我目前没有什么需要变现的内容，但这项技术似乎太重要了，以至于我不能不去尝试一下。那么，我们就开始吧。

## 2. 计划：自行实现 x402 协议

不幸的是，Cloudflare 的服务似乎仍处于封闭测试阶段（closed beta），这意味着目前你无法自由访问，需要加入等待列表。因此，我们只能自己动手实现。这其实更有趣，不是吗？幸运的是，它的设置相当简单。虽然这会给静态博客增加一些动态组件，但没有什么是一天之内不能附加上的。那么，我们需要什么来让这个东西工作呢？一个接收资金的钱包，一个执行支付处理逻辑的 Worker，以及一个我们想要设置支付墙（paywall）的资源。我拥有第1项和第3项，但没有第2项。目前，我将使用 Cloudflare Workers，因为我的网站就托管在那里。这也决定了我们将使用 TypeScript 作为实现语言。也许以后我会重新实现它，将其托管在我的本地服务器上，但为了控制实验范围，我们暂时坚持使用 Cloudflare。

## 3. 中间件：使用 Hono 框架实现支付逻辑

那么，让我们直接开始。我们需要的第一件事是一个中间件（middleware），它将接收请求，确保只有在支付后才授予访问权限，并处理价格披露。官方文档有一个如何在 Hono 中实现它的示例，所以我们将使用它。为了适应代码将在 Cloudflare Worker 而非独立服务器上运行的事实，我们进行了一些修改，添加了我们的钱包地址，并将示例端点替换为一个更有用的端点——我们得到了以下代码：

```typescript
import &#123; Hono &#125; from 'hono';
import type &#123; MiddlewareHandler &#125; from 'hono';
import &#123; paymentMiddleware, x402ResourceServer &#125; from '@x402/hono';
import &#123; ExactEvmScheme &#125; from '@x402/evm/exact/server';
import &#123; ExactSvmScheme &#125; from '@x402/svm/exact/server';
import &#123; HTTPFacilitatorClient &#125; from '@x402/core/server';

const app = new Hono();
const evmAddress = '0xD040AEACCdFf083C5D4cB221F1533e8719a84F0e';
const svmAddress = 'HjexCvNzgxJT3Ni7rb98WF4pQGEX2fN7G6Zh26B19mBc';
const facilitatorClient = new HTTPFacilitatorClient(&#123;
  url: 'https://x402.org/facilitator',
&#125;);

let payment: MiddlewareHandler | undefined;

app.use(async (c, next) =&gt; &#123;
  payment ??= paymentMiddleware(
    &#123;
      'GET /api/joke': &#123;
        accepts: [
          &#123;
            scheme: 'exact',
            price: '$0.01',
            network: 'eip155:84532',
            payTo: evmAddress,
          &#125;,
          &#123;
            scheme: 'exact',
            price: '$0.01',
            network: 'solana:EtWTRABZaYq6iMfeYKouRu166VU2xqa1',
            payTo: svmAddress,
          &#125;,
        ],
        description: 'A premium, hand-picked joke',
        mimeType: 'application/json',
      &#125;,
    &#125;,
    new x402ResourceServer(facilitatorClient)
      .register('eip155:84532', new ExactEvmScheme())
      .register('solana:EtWTRABZaYq6iMfeYKouRu166VU2xqa1', new ExactSvmScheme()),
  );
  return payment(c, next);
&#125;);

const jokes = [];
app.get('/api/joke', (c) =&gt; &#123;
  return c.json(&#123; joke: jokes[Math.floor(Math.random() * jokes.length)] &#125;);
&#125;);

export default app;
```

Worker 还需要一个 wrangler.jsonc 文件（Cloudflare 特定配置）：

```json
&#123;
  "name": "x402-poc",
  "main": "src/index.ts",
  "compatibility_date": "2026-07-01",
  "compatibility_flags": ["nodejs_compat"],
  "env": &#123;
    "production": &#123;
      "name": "x402-poc",
      "routes": [
        &#123;
          "pattern": "shtein.me/api/*",
          "zone_name": "shtein.me"
        &#125;
      ]
    &#125;
  &#125;
&#125;
```

其中有两个不明显的点：需要 `nodejs_compat`，因为 x402 包导入了 Node 内置模块（`events`、`crypto`、`url`），没有它构建会失败。路由特意只存在于生产环境中：定义了路由后，`wrangler dev` 会模拟路由的主机，因此中间件生成的 URL 将指向真实域名，而不是 localhost。

## 6. 总结：x402 对博客变现的适用性

x402 不仅适用于为 AI 代理设置支付墙，而且几乎已经准备好帮助你变现你的博客。无需摆弄像“Buy Me a Coffee”这样的服务，也无需用广告打扰你的用户。它很容易集成，即使是静态网站，尽管你需要一些计算资源。但不需要太多。目前还没有一个开箱即用的解决方案，可以为动态内容进行多网络支付，并将其嵌入到页面的 DOM 中。至少在这次短暂的探索中，我还没有找到。但浏览器似乎已经准备好为页面设置支付墙，这使得实现变得非常容易。

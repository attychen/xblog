摘要：理解大型复杂代码库，尤其是那些结构混淆且文档不完整的代码库，仍然是一项重大挑战。现有的代码摘要解决方案通常依赖单一语言模型或编码助手（如Claude Code），并将源代码视为平面文本，未能充分利用代码仓库中丰富的相互依赖关系和分层信息。为了解决这些不足，我们提出了Agent4cs——一个多智能体框架，它以自底向上的方式总结大型代码库：一个摘要智能体（summarization agent）专注于生成稳健的摘要；一个关键词提取智能体（keyword-extraction agent）主动从子文件夹中识别关键信息；一个质量保证智能体（quality-assurance agent）迭代优化输出，以提高可读性、连贯性和完整性。在7个前沿模型上评估，与两个使用代码片段的结构化提示基线相比，Agent4cs在所有文件夹层级上的语义一致性平均提高了8%。此外，在真实世界数据集上的广泛评估显示，与相同基线相比，归一化关键词覆盖率（normalized keyword coverage rate）提升了高达38%。
评论：已被第23届欧洲多智能体系统会议（EUMAS 2026）主轨接收。

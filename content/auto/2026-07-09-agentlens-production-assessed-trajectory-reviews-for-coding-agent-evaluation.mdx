## 1. 概述

我们提出AgentLens，一个面向交互式代码智能体（interactive code agents）的生产级评估基准。大多数代码智能体基准将一次运行简化为单一比特——任务是否通过？——但实际使用这些智能体的人体验的是完整的轨迹：智能体如何遵循指令、使用工具、验证自身工作、从错误中恢复，以及在此过程中如何与用户交流。AgentLens评估的就是整个轨迹。它将形式化验证（formal verification，存在客观检查时）与LLM撰写的轨迹审查（trajectory reviews）及并排比较（side-by-side comparisons）相结合，使得每次运行都能生成可读的解释，说明得分为何如此。这使得AgentLens不仅可用于模型排名：我们用它来诊断模型行为、比较自身智能体的连续版本，并在夜间评估流水线（nightly evaluation pipeline）中捕获产品回归。我们将该基准以开源形式发布在此链接：https://this URL。

## 2. 背景与动机

当前代码智能体评估方法存在显著局限：它们通常只关注最终结果（任务是否完成），而忽略了智能体在完成任务过程中的行为轨迹。然而，对于实际用户而言，智能体如何与用户交互、如何应对错误、如何逐步解决问题等过程性表现同样重要。AgentLens旨在填补这一空白，通过评估完整轨迹来提供更全面的智能体性能画像。

## 3. 方法：轨迹审查与评估

AgentLens的核心方法包括两个关键组件：形式化验证和LLM驱动的轨迹审查。形式化验证用于存在客观检查的任务（如代码正确性），提供硬性指标。LLM撰写的轨迹审查则评估智能体在交互过程中的行为质量，包括指令遵循、工具使用、错误恢复和用户沟通等方面。此外，AgentLens还支持并排比较，允许直接对比不同智能体或同一智能体不同版本在相同任务上的表现。

## 4. 应用场景

AgentLens不仅是一个排名工具，更是一个诊断和调试平台。我们将其用于：诊断模型行为（如识别特定失败模式）、比较自身智能体的连续版本（如新版本是否改进了错误恢复能力），以及在夜间评估流水线中捕获产品回归（如新部署是否引入了性能下降）。这些应用展示了AgentLens在生产环境中的实用价值。

## 5. 开源与可用性

AgentLens基准已作为开源项目发布，代码和数据均可通过上述链接获取。我们鼓励社区使用、扩展和改进AgentLens，以推动代码智能体评估领域的发展。

## 6. 结论与未来工作

AgentLens通过评估完整轨迹而非单一结果，为代码智能体提供了更全面、更实用的评估方法。未来工作将探索将AgentLens扩展到更多类型的智能体任务，并进一步优化LLM轨迹审查的准确性和效率。

## 1. 黑客被捕案揭露微软追踪能力

一名青少年黑客的被捕揭示了微软能够通过一个“全球设备ID”（Global Device ID）追踪Windows PC及其在线活动，且该ID似乎没有简单的退出选项，引发了人们对潜在监控的担忧。上周，美国宣布已从欧洲引渡19岁的彼得·斯托克斯（Peter Stokes），他涉嫌是臭名昭著的黑客组织Scattered Spider的成员。但此案之所以引人注目，是因为根据一份解封的刑事起诉书，微软在将斯托克斯与涉嫌黑客犯罪联系起来方面发挥了关键作用。

## 2. 全球设备ID（GDID）的工作原理

斯托克斯涉嫌于2025年5月在使用VPN（虚拟专用网络）的情况下，入侵了一家未具名的豪华珠宝零售商。这份39页的刑事起诉书显示，FBI（联邦调查局）利用微软的记录发现，他的IP地址与一个名为全球设备ID（GDID）的微软设备标识符相关联。起诉书解释称，据一位微软代表表示，“Windows生态系统中的全球设备标识符是一个持久的、设备级别的标识符，旨在唯一标识设备上（无论是物理设备，如手机或笔记本电脑，还是虚拟机）的Windows操作系统安装，用于某些微软服务和场景。”全球设备ID并不完全令人意外，因为为每个账户或设备分配唯一ID是标准做法，以便技术提供商能够识别和区分它们。但起诉书揭示，微软可以将GDID与第三方服务以及时间相关联，从而在理论上为微软提供了一种追踪用户在线活动的方式。换句话说，微软或许能够在不使用第三方浏览器cookies（网络追踪器）的情况下，追踪你Windows PC的在线活动。

## 3. 黑客如何被追踪

斯托克斯被发现利用一个名为ngrok的Web开发工具来绕过珠宝零售商的网络防御。起诉书称，微软的记录显示，在2025年5月12日19:21 UTC（协调世界时），与斯托克斯电脑关联的GDID访问了ngrok页面，其中包括“https://dashboard[.]ngrok.com/signup”，即用于设置ngrok账户的页面。文件补充说，微软的记录还显示该GDID从Tzulo（一家网络托管提供商）的服务器访问了多个网站，以协助实施黑客攻击。斯托克斯电脑的GDID据称为6755467234350028。

## 4. 监控担忧与隐私风险

因此，联邦调查人员利用微软标识符抓获一名涉嫌黑客的事实，引发了人们对其可能被滥用于其他监控目的的担忧。网络安全专家马修·希基（Matthew Hickey）在一条推文中声称：“微软Windows就是监控软件。”该设备ID在此支持页面上被简要提及，但微软尚未就此公开发表其他评论。根据刑事起诉书，Windows用户可以自行重置GDID，但这并不容易。法院文件称：“GDID在设备上的Windows操作系统更新中保持一致，但在同一设备或不同设备上重新安装Windows后，将关联到一个新的唯一GDID。”在脚注中，它补充道：“因此，一个微软用户可能拥有多个GDID。

## 5. 用户应对与行业反思

尽管如此，我们怀疑微软将新设置的GDID与旧GDID关联起来并不困难，因为该公司可以查看其他标识符，例如微软账户登录信息或IP地址，并进行匹配。针对这种监控潜力，一些用户已经在探索控制和清除GDID标识符的方法。与此同时，网络安全研究员科斯廷·拉尤（Costin Raiu）质疑，考虑到唯一标识符的使用，其他科技公司是否也具备同样的监控能力。他在《三兄弟问题》（Three Buddy Problem）播客中表示：“我还会问：这在苹果设备上发生了多少？规模相同吗？是否在更高层面上发生——他们是否将其与硬件绑定，这样即使你重新安装系统，也没关系，因为它是基于硬件的？”“很可能这并非微软独有。而且，如果你想完全匿名，你可能在某些时候不得不在开发环境中使用Linux、FreeBSD等系统，并通过代理、Tor（洋葱路由）、VPN等工具隧道化所有流量。”
